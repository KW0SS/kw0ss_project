# exp_005: fixed_N 다중공선성 후보 제거 실험 리포트

> 실험일: 2026-05-15  
> Base: `results/exp_004_fixed_N`  
> 변경점: `유동비율`, `유형자산상각비` 2개 피처 제거 후 동일 조건 재학습

---

## 0. 실험 목적

`exp_004_fixed_N` 학습은 EDA에서 다중공선성 제거 후보로 확인된 `유동비율`, `유형자산상각비`를 포함한 상태로 수행됐다. 이번 실험은 나머지 조건을 유지하고 해당 2개 피처만 제거했을 때 fixed_N 모델 성능이 유지되는지 확인한다.

### 제거 피처

| 피처 | 제거 사유 |
|---|---|
| `유동비율` | `당좌비율` 등 유동성 계열과 높은 상관. 유사한 유동성 신호가 중복될 가능성 |
| `유형자산상각비` | `감가상각비`와 높은 상관. 감가상각 계열 원시값 신호 중복 가능성 |

적용 위치는 `src/modeling/data_loader_fixed.py`이며, fixed_N 학습 시 feature 수는 33개에서 31개로 줄었다.

```text
fixed_N1 features=31 excluded=['유동비율', '유형자산상각비']
fixed_N2 features=31 excluded=['유동비율', '유형자산상각비']
```

---

## 1. 실행 조건

`exp_004`와 동일하게 N1/N2, 4개 전처리 variant, 5개 모델 조합을 학습했다.

```bash
.venv/bin/python -m src.modeling.run_all_fixed \
  --exp exp_005_fixed_N_collinear_drop \
  --n 1 2 \
  --variant baseline exp-A exp-B exp-C
```

| 항목 | exp_004 | exp_005 |
|---|---|---|
| Dataset | fixed_N1, fixed_N2 | 동일 |
| Variant | baseline, exp-A, exp-B, exp-C | 동일 |
| Model | RF, GBM, XGBoost, LightGBM, LogReg | 동일 |
| Threshold | valid F1 최적화 | 동일 |
| Feature count | 33 | 31 |
| 변경 피처 | 없음 | `유동비율`, `유형자산상각비` 제거 |

## 2. 전체 결론

다중공선성 후보 2개를 제거해도 **best PR-AUC는 거의 유지**됐다. 다만 exp_004의 best 모델이었던 `RF N1 exp-C`의 F1과 recall은 하락했다.

| 구분 | Model | N | Variant | PR-AUC | F1 | Precision | Recall | ROC-AUC |
|---|---|---:|---|---:|---:|---:|---:|---:|
| exp_004 best | RF | 1 | exp-C | 0.2861 | 0.3529 | 0.3333 | 0.3750 | 0.8595 |
| exp_005 best | RF | 1 | exp-A | 0.2841 | 0.2759 | 0.3871 | 0.2143 | 0.8620 |
| 변화 | - | - | - | -0.0020 | -0.0770 | +0.0538 | -0.1607 | +0.0025 |

해석:

- PR-AUC 기준으로는 제거 전후 차이가 매우 작아, 두 피처가 ranking 성능의 핵심은 아니었다.
- RF 계열에서는 threshold 적용 후 recall이 줄고 precision이 올라가는 방향으로 변했다.
- best 모델 관점에서는 `exp_004 RF N1 exp-C`를 대체할 만큼 개선되지는 않았다.

## 7. 결론

### 판단

`유동비율`, `유형자산상각비` 제거는 **모델 단순화에는 유효하지만, exp_004 best 성능을 개선하지는 못했다.**

| 선택지 | 판단 |
|---|---|
| exp_004 유지 | PR-AUC/F1 기준 best 유지. RF N1 exp-C가 여전히 가장 강함 |
| exp_005 채택 | feature 수 2개 감소, PR-AUC 거의 유지. 단 RF recall/F1 하락 |

### 추천

- 운영 후보 모델은 기존 `exp_004 RF fixed_N1 exp-C`를 유지한다.
- 다중공선성 제거 버전은 ablation 결과로 보관한다.
- feature 수를 줄이는 것이 목적이라면 `exp_005 RF fixed_N1 exp-B/baseline`도 후보가 될 수 있으나, recall 하락을 threshold 재탐색으로 보정해야 한다.
- 후속 실험에서는 피처 제거 자체보다 threshold 안정화와 RF hyperparameter tuning이 더 우선순위가 높다.
