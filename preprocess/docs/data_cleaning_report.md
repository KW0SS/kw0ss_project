## TL;DR (3줄 요약)

1. **데이터 4종 정합성 이슈를 발견하고 수정**했습니다. 가장 큰 변화는 종목코드 재사용으로 인한 시간역행 데이터 제거(83행)와 raw 폴더 중복 데이터 제거(1,922행)입니다.

## 2. 4.27 모델 결과 재현성 — 주의사항

이 데이터로 모델을 재학습하면 4.27 보고서와 **직접 비교가 어렵습니다**. 다음 두 가지 변화 때문입니다:

### (1) 우리 작업으로 인한 변화 (정합성 개선)
- 시간역행 데이터 제거 → 학습 데이터에서 노이즈 제거
- 중복 dedup → 일부 샘플의 과대 가중 제거
- **방향성**: 데이터 품질 향상. 모델 성능에 미치는 영향은 미미할 수도 있고, 양쪽으로 갈 수도 있음.

### (2) 외부 변경으로 인한 변화 (작업 외 영역)
- **데이터 수집 보강**: 모든 연도에서 행수 +0.5~3.2% 증가 (전체 +1.8%)
  - 누락된 분기를 추가 수집
- **섹터 매핑 갱신**: KSIC→GICS v4 매핑 적용으로 일부 기업의 섹터 재분류
  - Consumer Staples 89 → 1,092, Financials 75 → 684 등
  - 단, gics_sector는 학습 피처에서 제외(META_COLUMNS)되므로 모델 성능 영향 없음

따라서 모델 성능이 4.27 결과보다 좋아진다면 **데이터 품질 개선 + 데이터량 증가 + 양성 샘플 증가**의 종합 효과이며, 정확한 기여도 분리는 어렵습니다.

## 4. 권장 사항 — 다음 모델 학습 시

이번 정제 결과를 활용한 모델 재학습 시, 4.27 보고서의 **"다음 실험 방향"**과 별개로 추가 검증을 권장합니다:

### 우선순위 높음
1. **새 데이터로 동일 조건 baseline 재학습** (RF, H10/H12 우선)
   - 4.27 결과 (PR-AUC 0.10/0.20)와 비교
   - 양성 24% 증가가 평가 안정성에 어떤 영향을 주는지 확인

2. **Bootstrap 신뢰구간(CI) 산출**
   - 4.27 보고서의 PR-AUC 0.10이 진짜 0.10인지, 0.05~0.18 사이 어디인지 검증
   - test 양성이 늘어 CI가 좁아질 것으로 예상

3. **Permutation test (stock_code 의존도)**
   - train/test 기업 중복률이 88~100%로 매우 높음 (별도 검증 결과)
   - stock_code feature 제외는 확인됐으나, 다른 feature를 통한 우회 학습 여부 검증

### 그 다음
4. 4.27 보고서의 기존 우선순위 (Optuna 튜닝, horizon 확장, threshold 전략) 진행
